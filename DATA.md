# Data and checkpoints

## Bundled trajectory export

`data/bird_trajs.jsonl` contains 2,197 trajectory windows from 44 track IDs. Every window has 8 observed steps and 12 future steps. A record has this form:

```json
{"tid": 7, "hist": [[1, 0.50, 0.25, 0.10, 0.10]], "fut": [[2, 0.52, 0.26, 0.10, 0.10]]}
```

The example is shortened to one step. Each row is `[frame, center_x, center_y, box_width, box_height]`, with spatial values expressed relative to image dimensions. The forecaster uses only the center coordinates and converts them once with `2 * xy - 1`. It does not infer metres or reconstruct pixels from this export.

Track IDs are available; source-video IDs, camera calibration, original paper partitions and a dataset-release identifier are absent. The reference runner groups by track ID, not by individual window, to avoid overlapping windows of the same identified track leaking between splits. This cannot establish independence between unidentified source videos or birds.

## Alternative pixel-coordinate schema

The loader also accepts:

```json
{"video": "clip-01", "track_id": 7, "W": 1920, "H": 1080, "past": [[960, 540]], "future": [[970, 545]]}
```

Use nonempty finite two-dimensional coordinate arrays, positive image dimensions, and equal observed/future lengths throughout one file. The loader checks these conditions and reports the line of a malformed record. All records should use a consistent schema and coordinate convention.

Three or more known video groups enable video-level splitting. Otherwise the runner groups by `(video, track_id)` and requires at least three identified tracks.

## Checkpoints and other artifacts

- `hivt_data/`: small historical baseline exports, independent of the reference runner's newly generated split.
- `checkpoints/lstm_forecast.pt` and `checkpoints/yolov8n.pt`: historical baseline/detector artifacts, not Student-t reference-run checkpoints.
- `output/<run>/best.pt`: generated by `forecast.py`; contains model settings, data SHA-256, exact partition indices, seed and selected epoch.
- Raw videos, complete research datasets, original paper split manifests, calibration metadata and complete paper-model checkpoints are not distributed through the supported quick start.

Only load checkpoints from a trusted source. The reference loader uses `weights_only=True` and strict parameter matching. A fingerprint mismatch stops evaluation rather than silently constructing a new partition.
