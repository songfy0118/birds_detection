# YOLOv5s with AFPN for Bird Detection

Project page for **Asymptotic feature pyramid based YOLOv5s for birds detection**.

## Publication

Jiajie Cai, Han Huang, Feiyang Song. *Journal of Physics: Conference Series*, 2711, 012007, 2024. The paper states that all authors contributed equally.

- [Published article](https://doi.org/10.1088/1742-6596/2711/1/012007)
- [Full text](https://www.researchgate.net/publication/378540307_Asymptotic_feature_pyramid_based_YOLOv5s_for_birds_detection)

## Research

The paper investigates replacing the YOLOv5s feature pyramid with AFPN and comparing SIoU, WIoU and EIoU bounding-box regression losses. Its bird subset is derived from VOC2012.

This project concerns bird **detection**. The Transformer-based trajectory forecasting project is documented in the repository's root README.
